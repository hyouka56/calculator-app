# Flutter Calculator App

A simple and functional calculator application built with Flutter.

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Clear button (C) to reset the calculator
- Backspace button (⌫) to delete the last digit
- Decimal point support
- Responsive button layout
- Material Design 3 styling

## Getting Started

### Prerequisites

- Flutter SDK (>=3.16.0)
- Dart SDK (>=3.2.0)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hyouka56/calculator-app.git
   cd calculator-app
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

## Usage

- Tap number buttons to input numbers
- Tap operation buttons (+, -, ×, ÷) to perform calculations
- Tap = to see the result
- Tap C to clear the calculator
- Tap ⌫ to delete the last entered digit
- Tap . to add a decimal point
